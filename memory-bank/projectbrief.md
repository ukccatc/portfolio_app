# Project Brief: Oleg Rostovtsev Portfolio

Personal portfolio website for Oleg Rostovtsev (Odessa, Ukraine). Single-page Flutter Web site used to present skills, work history, projects, education, and contact details.

## Scope

- Responsive one-page site (desktop / tablet / mobile)
- Content-driven: copy lives in `lib/src/utils/data.dart`
- Deployed to GitHub Pages from `main` via `.github/workflows/gh_pages_deploy.yml`

## Out of scope

- Backend, CMS, auth, blog, analytics
- Native mobile/desktop apps as a product (web is the target)
