# Product Context

A hiring-oriented portfolio. Visitors should quickly see who Oleg is, what he has built, and how to contact him.

## Sections

1. Hero — name, role, short goal, contact CTA
2. Skills — chips grouped by Backend / Frontend / DevOps
3. Experience — timeline cards
4. Projects — project cards
5. Education — school/course list
6. About — bio and interests
7. Contact — details, social links, mailto form

## Content rule

Update text in `lib/src/utils/data.dart`. Do not hardcode copy in widgets unless it is UI chrome (section titles, button labels).
